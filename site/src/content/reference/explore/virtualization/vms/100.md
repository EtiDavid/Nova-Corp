# VM 100 — nova-fw01

**Power state:** **Running** · **vCPU:** 2 cores · **RAM:** 2 GiB · **BIOS/machine:** Not explicitly specified in the documented VM configuration.

## What this virtual machine does

pfSense routes traffic between Nova Corp's networks, enforces firewall rules, serves DHCP/DNS Resolver and hosts WireGuard.

## Virtual networking — which network does it join?

| NIC | Proxmox bridge | VLAN tag | Meaning |
|---|---|---|---|
| `net0` | [`vmbr0`](/reference/explore/virtualization/bridges/vmbr0/) | no tag | pfSense WAN vtnet0; upstream router |
| `net1` | [`vmbr1`](/reference/explore/virtualization/bridges/vmbr1/) | no tag | pfSense LAN vtnet1 and tagged VLANs 10–50 |

## Disk and media attachments — exact configuration

| Device | Storage | Declared size | Role |
|---|---|---|---|
| `scsi0` | [`local-lvm`](/reference/explore/virtualization/storages/local-lvm/) | 16G | pfSense VM disk |
| `ide2` | `none` | — | Empty CD-ROM |

## Operational detail and recovery note

VM100 is the only VM with a current Proxmox snapshot. The backup store also contains four vzdump archives for it, including the fresh CR-015 baseline.

**The Proxmox state is not a Windows/pfSense application health test.** For runtime behavior, follow the service and incident links below.
