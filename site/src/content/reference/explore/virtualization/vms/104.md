# VM 104 — nova-files01

**Power state:** **Running** · **vCPU:** 2 cores · **RAM:** 4 GiB · **BIOS/machine:** q35 (EFI BIOS not explicitly specified)

## What this virtual machine does

Windows file server hosts departmental SMB shares, DFS namespace targets, Shadow Copies and Windows Server Backup.

## Virtual networking — which network does it join?

| NIC | Proxmox bridge | VLAN tag | Meaning |
|---|---|---|---|
| `net0` | [`vmbr1`](/reference/explore/virtualization/bridges/vmbr1/) | 20 | INFRA / 10.10.20.20 as last verified inside Windows |

## Operational detail and recovery note

The 100G qcow2 on nova-backup is an attached live VM disk, not a compressed vzdump archive. The verified recovery incident for FILES01 used its Windows-level backup target B:, not a VM104 vzdump archive.

A running virtual machine does not automatically mean its services are healthy. Explore the linked service tests to see how it performs.
