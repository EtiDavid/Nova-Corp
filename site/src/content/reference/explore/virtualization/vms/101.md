# VM 101 — nova-dc01

**Power state:** **Running** · **vCPU:** 2 cores · **RAM:** 4 GiB · **BIOS/machine:** OVMF / q35

## What this virtual machine does

Windows Domain Controller 01 runs Active Directory Domain Services, DNS and authentication services.

## Virtual networking — which network does it join?

| NIC | Proxmox bridge | VLAN tag | Meaning |
|---|---|---|---|
| `net0` | [`vmbr1`](/reference/explore/virtualization/bridges/vmbr1/) | 20 | INFRA / 10.10.20.10 as last verified inside Windows |

## Disk and media attachments — exact configuration

| Device | Storage | Declared size | Role |
|---|---|---|---|
| `scsi0` | [`local-lvm`](/reference/explore/virtualization/storages/local-lvm/) | 80G | Main Windows OS disk |
| `scsi1` | [`nova-backup`](/reference/explore/virtualization/storages/nova-backup/) | 60G | Active qcow2 VM data disk; backup flag 0 |
| `efidisk0` | [`local-lvm`](/reference/explore/virtualization/storages/local-lvm/) | 4M | UEFI firmware state |
| `tpmstate0` | [`local-lvm`](/reference/explore/virtualization/storages/local-lvm/) | 4M | Virtual TPM state |
| `ide2` | [`local`](/reference/explore/virtualization/storages/local/) | 771138K | VirtIO driver ISO |
| `ide0` | `none` | — | Empty CD-ROM |

## Operational detail and recovery note

A 60G live qcow2 disk on nova-backup is not automatically a backup archive. Two separate archived vzdump backups for VM101 are listed (both dated June 2026).

A running virtual machine does not automatically mean its services are healthy. Explore the linked service tests to see how it performs.
