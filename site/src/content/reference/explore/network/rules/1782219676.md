# Allow infrastructure network traffic.

**Firewall rule ID:** `1782219676` · **Action:** **PASS** · **Interface:** [INFRA](/reference/explore/network/zones/INFRA/), position **1**

## What does it do?

DC01, DC02 and FILES01 are located on INFRA. The rule permits broad IPv4 traffic originating there; it is not an application-specific allowlist.
