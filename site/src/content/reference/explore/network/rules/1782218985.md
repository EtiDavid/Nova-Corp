# Allow management-area IPv4 traffic outbound.

**Firewall rule ID:** `1782218985` · **Action:** **PASS** · **Interface:** [MGMT](/reference/explore/network/zones/MGMT/), position **2**

## What does it do?

The configured MGMT rule is broadly permissive; the Phase 2 security review separately blocked ordinary CLIENT traffic to the management network.
