# Allow application-area IPv4 traffic.

**Firewall rule ID:** `1782219739` · **Action:** **PASS** · **Interface:** [APP](/reference/explore/network/zones/APP/), position **1**

## What does it do?

The APP network exists as a prepared segment. This rule is permissive; a deployed application server is not evidenced by its presence.
