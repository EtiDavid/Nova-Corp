# Allow approved UDP domain services from VPN.

**Firewall rule ID:** `1785019484` · **Action:** **PASS** · **Interface:** [VPN_REMOTE](/reference/explore/network/zones/VPN_REMOTE/), position **3**

## What does it do?

This rule permits UDP 53, 88, 123, 389 and 464 to the Domain Controller host alias.
