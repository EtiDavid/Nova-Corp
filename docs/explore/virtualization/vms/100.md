# VM 100 — nova-fw01

**Power state:** **Running** · **vCPU:** 2 cores · **RAM:** 2 GiB · **BIOS/machine:** Not explicitly specified in the documented VM configuration.

## What this virtual machine does

pfSense routes traffic between Nova Corp's networks, enforces firewall rules, serves DHCP/DNS Resolver and hosts WireGuard.

## Virtual networking — which network does it join?

| NIC | Proxmox bridge | VLAN tag | Meaning |
|---|---|---|---|
| `net0` | [`vmbr0`](../bridges/vmbr0.md) | no tag | pfSense WAN vtnet0; upstream router |
| `net1` | [`vmbr1`](../bridges/vmbr1.md) | no tag | pfSense LAN vtnet1 and tagged VLANs 10–50 |
