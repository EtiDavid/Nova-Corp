# pfSense's retained known-good snapshot

**VM:** [100 — nova-fw01](../vms/100.md)  
**Snapshot:** `pre-cr016-known-good-20261120`  
**Role:** Known-good pfSense rollback before the next security change.

## Why it exists

Nova Corp completed Phase 2 network hardening and preserved a named point to return to **before** starting the planned next privileged-management security change.

The Proxmox setup shows it is currently the **only retained VM snapshot** among the six VMs.

## What does it protect?

It is a point-in-time snapshot of the pfSense VM disk on the same thin pool. If a later configuration change breaks pfSense, an operator can consider rollback after checking the applicable recovery runbook.

**Important difference:** this is a fast rollback point—not an off-host backup. Nova Corp also preserved a separate pfSense whole-VM `vzdump` archive and a private configuration export.
