# Allow approved TCP domain services from VPN.

**Firewall rule ID:** `1785002175` · **Action:** **PASS** · **Interface:** [VPN_REMOTE](../zones/VPN_REMOTE.md), position **2**

## What does it do?

This rule uses both a host alias and a port alias. It covers TCP 53, 88, 135, 389, 445, 464, 3268 and 49152–65535, as configured.
