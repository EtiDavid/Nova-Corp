# WireGuard can receive remote connection packets.

**Firewall rule ID:** `1785021391` · **Action:** **PASS** · **Interface:** [WAN](../zones/WAN.md), position **1** · **Captured:** 22 November 2026.

## What does it do?

This is an inbound WAN rule for the WireGuard listener. The rule allows packets through the firewall; the WireGuard peer still has to authenticate.
