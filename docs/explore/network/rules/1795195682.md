# Block employee clients from the management network.

**Firewall rule ID:** `1795195682` · **Action:** **BLOCK** · **Interface:** [CLIENT](../zones/CLIENT.md), position **2**

## What does it do?

This second CLIENT block stops traffic destined for MGMT. An unrelated network such as INFRA may still be reachable through the broader CLIENT allow rule.
