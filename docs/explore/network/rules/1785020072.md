# Block all other VPN access to INFRA.

**Firewall rule ID:** `1785020072` · **Action:** **BLOCK** · **Interface:** [VPN_REMOTE](../zones/VPN_REMOTE.md), position **5** · **Captured:** 22 November 2026.

## What does it do?

After the specific Domain Controller permits, this rule blocks remote VPN traffic to other infrastructure destinations, including services not previously allowed.
